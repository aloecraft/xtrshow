The loop

Two commands. xtrshow gets code into the model, xtrpatch gets it back out.

  1. 1

    Extract

    Pick files in a keyboard-driven TUI. Output is line-numbered and headed with --- a/path, so the model can anchor edits to exact locations.

    $ xtrshow | pbcopy
  2. 2

    Prompt

    Paste the context into any LLM along with the patch-format instructions.

    $ xtrshow -p
  3. 3

    Apply

    Save the reply and apply it. Every touched file is backed up first, and --revert unwinds the whole patch.

    $ xtrpatch xpatch.txt

Try it live

A working shell with your file on the left, the model's reply on the right, and a real terminal underneath. Every command you run drives the actual xtrpatch engine, which is the Python package itself, compiled to WebAssembly. Nothing is sent to a server, and both editors are yours to change.

Why not just unified diffs?

  

    LLMs are unreliable at producing valid unified diffs. Line numbers drift,
    context lines get hallucinated, and one bad hunk poisons the file.
    xtrpatch uses a Search & Replace block format designed
    around how models actually fail.
  


  

    
--- a/path/to/file.py
@ optional: describe the change
<<<< LINE_HINT
[code to find]
====
[code to replace it with]
====
[optional tail: line that must follow]
>>>>


    
    
      
  • Fuzzy whitespace matching absorbs the indentation errors models constantly make.
    • 
      
  • Wildcard anchors (~~~~) let the model match on stable signatures and skip volatile interior lines.
    • 
      
  • Line hints (<<<< 42) disambiguate when the same block appears more than once.
    • 
      
  • Tail context guards a match with a lookahead, so a hunk never lands in the wrong place.
    • 
      
  • Per-hunk annotations (@ why) surface in the apply report, so failures are self-describing and feed straight back into the LLM.
    •

Features

  

    

      
📂 Interactive TUI

      
Fast, keyboard-driven file selection with directory expand/collapse and live size stats.

    

    

      
🔢 LLM-optimized output

      
Line-numbered content with --- a/path headers the patcher can target.

    

    

      
🧹 Smart filtering

      
Ignores node_modules, .git, build artifacts and friends by default.

    

    

      
💾 Safety first

      
Automatic, versioned backups in .xtr/backup/ before every modification.

    

    

      
🔐 Checksum verification

      
Warns when a file was edited outside the patch loop since the last apply.

    

    

      
⚡ Conflict detection

      
Overlapping hunks are caught pre-flight and skipped, never blindly stacked.

    

    

      
🧠 Idempotent

      
Re-applying a patch detects already-applied hunks and skips them.

    

    

      
↩️ Undo button

      
--revert restores the most recent backup per file, or every file in a patch.
